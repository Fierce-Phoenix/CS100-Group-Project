# Design notes

The previous visual pass added too many decorative treatments: a prominent brand mark, pill controls, soft cards, shadows, accent surfaces and a full-width accessibility toolbar. This revision removes those additions.

The interface now uses:
- one Arial/Helvetica font stack throughout;
- white backgrounds, black text and a single restrained blue link colour;
- thin grey rules instead of layered cards and shadows;
- plain text navigation with only the links needed for each account role;
- compact, conventional form controls and buttons;
- an expandable accessibility toolbar, so its features remain available without taking over the page;
- no entrance animations or hover lift effects.

Berkshire Hathaway's official site is a useful reference for prioritising direct access to information over visual effects. Its structure is mostly a heading, address and straightforward links. OrderFood still needs search, ordering, payments, maps and role-based dashboards, so this revision keeps those interactions while removing decoration that does not help users complete a task.

The no-ai-slop skill is a writing/editing skill rather than a UI specification. Its useful design parallels are minimum effective changes, concrete labels, no empty promotional copy, no repeated decoration and preserving the product's actual purpose.
